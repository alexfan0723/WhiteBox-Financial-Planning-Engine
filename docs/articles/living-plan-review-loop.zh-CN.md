# 规划是一项持续决策：假设、复核日期与变化触发条件

![假设复核循环](../../assets/assumption-review-loop.svg)

[English](living-plan-review-loop.md)

家庭规划往往从一个当下的问题开始，例如现在能否买房、调整投资、增加保障，或提前准备退休。但任何一个当下看似合理的答案，都依赖于收入、支出、家庭责任、流动性和时间安排等条件。条件变化后，原来的答案也应当重新接受检视。

## 规划不是一次性的答案

规划不是把一组数字算到某个结论后就结束。它是一个跨越多个生活阶段的决策过程。子女教育、按揭偿还、父母支持、职业转换、退休准备和保障责任，并不会在同一时间发生，也不会以同样的速度变化。

因此，一份严谨的规划应说明它适用于哪些条件，而不只给出一个方向。它需要让家庭与专业人士看见，哪些责任不能轻易削减，哪些选择仍有调整空间，以及哪些变化会使原先的比较失去基础。

## 假设需要来源、期限与影响范围

假设不是缺点。未来收入、支出增长、资产流动性和退休时间都不可能在今天被完全确认。问题不在于使用假设，而在于把假设误认为事实，或忘记它们何时需要重新检查。

有用的假设至少应回答三个问题：它依据什么信息；预计在多长时间内适用；如果变化，会影响哪些目标、责任或可选方案。比如，预期收入稳定可能支持当前储蓄安排，但若它同时承担按揭、教育和养老准备，就应明确收入中断时哪些承诺优先、哪些选择需要暂缓。

## 用日期和事件触发复核

复核不必等待出现问题才开始。规划可以设定清晰的日期，例如每年一次，或在教育、退休、贷款重定价等重要节点前后进行。它也应识别事件触发条件，例如收入显著变化、家庭成员责任增加、重大医疗或照护需求、资产难以变现，或政策和合同条件发生变化。

这些触发条件不是自动建议，更不是对未来的预测。它们的作用是提醒家庭：原先的假设可能已不再适用，应重新比较不同路径并确认优先级。

## 专业复核仍是决策边界

WhiteBox 的公开研究方向，是让事实、假设、约束、备选情景和待复核问题保持清晰可见。系统可以帮助组织问题，不能替家庭决定价值取舍，也不能代替专业人士对信息完整性、适当性和现实约束作出判断。

好的规划不是承诺永远不变的答案。它是在变化发生时，仍能说明为何需要复核、哪些责任优先，以及哪些选择值得重新讨论的过程。

*本文仅用于公共教育和研究讨论，不构成个人财务、投资、保险、法律或税务建议。*
